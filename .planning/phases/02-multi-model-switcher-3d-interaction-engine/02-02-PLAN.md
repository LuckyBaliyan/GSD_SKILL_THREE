    - Add explanatory comments on top of every function.
    - Function `createModelSwitcher(scene, models)`:
      - `models`: Array of `{ name, group, baseScale, baseRotation }` for Sunglasses, Perfume, and Watch.
      - Sets initial state: active index 0 visible, indices 1 and 2 invisible (`group.visible = false`, `scale = 0`).
      - Manages transition state `{ isTransitioning, fromIndex, toIndex, progress }`.
      - Function `switchModel(newIndex)`:
        - If same index or currently transitioning, return early.
        - Animates the outgoing model: shrinks scale from baseScale to 0 with rotational spin.
        - Once shrunk, hides outgoing model, reveals incoming model, and scales up to baseScale.
        - Emits callback on model change so UI pills can update their active class.
      - Function `setFinish(finishName)`:
        - Calls `applyFinish(finishName)` from `materials.js`.
      - Exposes `update(deltaTime)` hook to advance transition easing in the render loop.
      - Returns `{ switchModel, setFinish, getActiveGroup, update }`.
    - Ensure file is strictly under 130 lines with function comments.

  <files>src/three/animator.js</files>
  <read_first>src/three/scene.js</read_first>
  <action>
    Upgrade `src/three/animator.js`:
    - Add comments on top of every function explaining drag physics, momentum, and lerp.
    - Track pointer interaction:
      - `isDragging = false`, `previousPointerX`, `previousPointerY`.
      - `velocityX = 0`, `velocityY = 0`, `dragRotationX = 0`, `dragRotationY = 0`.
      - Listeners on `container`: `pointerdown`, `pointermove`, `pointerup`, `pointercancel`.
      - When pointer is dragging: update rotation directly from delta move:
        `dragRotationY += deltaX * 0.008`, `dragRotationX += deltaY * 0.008`.
        Record velocity based on last movement.
      - When pointer is released: on every frame multiply `velocityX *= 0.92`, `velocityY *= 0.92`.
        Add remaining velocity into `dragRotationY` and `dragRotationX`.
      - When drag velocity is low: combine gentle idle floating (`Math.sin(time * 1.5) * 0.12`) and cursor tilt parallax with the user's chosen viewing angle.
      - Call `switcher.update(deltaTime)` to advance model swap transitions smoothly.
    - Ensure file is strictly under 140 lines with function comments.
  </action>

  <name>Task 3: Float Physics & Mouse Parallax Animator</name>
  <files>src/three/animator.js</files>
  <read_first>src/three/scene.js, src/three/models.js</read_first>
  <action>
    Create `src/three/animator.js`:
    - Add descriptive comments on top of every function explaining its working.
    - Function `createAnimator(scene, camera, renderer, modelGroup, container)`:
      - Tracks mouse state `{ targetX: 0, targetY: 0, currentX: 0, currentY: 0 }`.
      - Mousemove listener on `window` (or container) normalizes cursor to -1 .. 1.
      - Continuous `requestAnimationFrame` render loop:
        - Calculates elapsed time.
        - Applies gentle harmonic floating: `modelGroup.position.y = Math.sin(time * 1.5) * 0.12`.
        - Applies base idle rotation: `modelGroup.rotation.y += 0.005`.
        - Interpolates mouse movement with linear interpolation (`lerp` factor 0.05) for silky smooth inertia.
        - Tilts model subtly based on lerped cursor: `modelGroup.rotation.x = currentY * 0.35` and adds cursor offset to `modelGroup.rotation.y`.
        - Calls `renderer.render(scene, camera)`.
      - Exposes clean cleanup / pause hooks if needed.
    - Keep file under 120 lines.
  </action>
